How to Remove Background in OBS Without a Green Screen

Removing your webcam background in OBS is one of the most searched streaming questions — and for good reason. A clean, distraction-free background makes your stream look professional instantly. The problem is that most guides tell you to either buy a green screen or install a plugin. This tool does neither.

This browser-based tool uses Google's MediaPipe AI model to detect and remove your background in real-time at up to 30 FPS — directly in your browser, with no installation required. The output is a clean canvas element you add to OBS as a Browser Source.

💡 Pro Tip: After adding the Browser Source in OBS, right-click it in the preview and select Filters → Chroma Key if you're using a solid color background. Or use transparent mode and just check "Allow Transparency" in the Browser Source settings.

OBS Background Removal: Plugin vs Browser Source

There are two main ways to remove your background in OBS:

  1. OBS Background Removal Plugin — A downloadable plugin (royshilkrot's Background Removal) that adds a filter directly to your OBS webcam source. Excellent performance, but requires installation and may not work on all systems.
  2. Browser Source (this tool) — No installation. Open the tool, allow camera access, and add the URL to OBS as a Browser Source. Works on Windows, Mac, and Linux without touching OBS settings.

When to Use the Browser Source Method

  • You can't install plugins (school/work computer, locked-down system)
  • The OBS plugin isn't available for your OS version
  • You want a quick test without committing to an install
  • You need a custom background image without plugin configuration

What Does "Allow Transparency" Mean in OBS?

When you add a Browser Source in OBS, the "Allow Transparency" checkbox tells OBS to respect the alpha channel (transparent pixels) in the browser output. If you choose "Transparent" mode in this tool and check that box in OBS, your webcam will appear with a completely transparent background — no green spill, no artifacts.

If you don't check it, OBS will show the checker pattern (transparency) as black, so always enable it when using transparent background mode.

Does This Work for Streamlabs OBS?

Yes. Streamlabs OBS also supports Browser Sources with the same "Allow Transparency" option. The setup steps are identical — add a new Browser Source, paste the URL, set resolution, and check Allow Transparency.

System Requirements

The AI model runs in your browser using WebAssembly and WebGL acceleration. Most laptops and desktops made after 2018 can run it smoothly at 30 FPS. Chrome and Edge give the best performance. Firefox is supported but may run at a slightly lower frame rate due to WebGL handling differences.
