# claude response

Not fully correct — it's not that Google "deprioritizes tool sites." It's that **pure tools (input box + button, no text) = "thin/low value content"** because there's nothing for Google to judge quality on.

**Real reasons for rejection (usually):**
1. Tool pages have little/no written text (just UI)
2. No blog/content section showing expertise
3. Site too new / inconsistent traffic history
4. Missing About, Privacy Policy, Contact pages
5. Looks "built to run ads," not to help users

**Fix — don't remove the tool, add around it:**
- Keep tool as homepage, but add: how-it-works section, use cases, FAQ (300-600 words)
- Add a blog (5-10 posts) on OBS/streaming topics — this is what "content" Google actually evaluates
- Add About page (who you are, credibility)
- Wait for site age: 3-6 months of consistent traffic helps a lot
- Check Privacy Policy, Terms, Contact — all present and real

Your obsmaskgenerator homepage tool is fine to keep — just needs supporting text content + a blog around it, not a full replacement.
