How to Set Hotkeys in OBS

  1. Open OBS → Settings → Hotkeys
  2. Find the action you want (e.g., "Start Streaming")
  3. Click the empty box next to it
  4. Press your desired key (e.g., F9)
  5. Click Apply

Pro Tips

  • Use function keys (F1-F12) - Less likely to conflict with games
  • Numpad for scenes - Quick, intuitive switching
  • Avoid common game keys - WASD, E, F, etc.
  • Use Stream Deck - Physical buttons for complex macros

FAQ

Why don't my hotkeys work?

OBS might not have focus. Enable "Focus Workspace" in Settings → Advanced, or use a Stream Deck for global hotkeys.

How do I use hotkeys while in a game?

Run OBS as administrator, or use keys that aren't used by the game (function keys work well).

Advanced Hotkey Setups

Basic hotkeys get you started. These advanced setups are what professional streamers use to run smooth, professional broadcasts:

  • Stream Deck integration: The Elgato Stream Deck maps physical buttons directly to OBS hotkeys. Each button has a customizable icon. This eliminates keyboard memorization entirely — you see exactly what each button does at a glance. Essential for any streamer doing 10+ hours per week.
  • Numpad hotkeys: If you have a numpad, map your scene switches to Num1–Num9. The numpad is physically separate from your gaming keys, so you'll never accidentally trigger a scene switch during gameplay.
  • Modifier keys: Use Ctrl, Alt, or Shift as modifiers to double your hotkey count without running out of keys. For example: F1 = Switch to Game Scene, Ctrl+F1 = Switch to BRB Screen.

Frequently Asked Questions

Do OBS hotkeys work when OBS is not the active window?

By default, no. OBS hotkeys only work when OBS is in focus. To make hotkeys work while gaming, enable System-wide Hotkeys in Settings > Hotkeys. Note: system-wide hotkeys can conflict with game keybindings, so test thoroughly before going live.

How do I set a hotkey to mute only desktop audio (not mic)?

In OBS, go to Settings > Hotkeys. Scroll down to find your "Desktop Audio" source. There will be separate mute hotkeys for each audio source. Assign one hotkey to mute "Desktop Audio" and a separate hotkey to mute your "Mic/Aux" source.

What's the best hotkey for push-to-talk?

The most popular choices are Caps Lock (rarely needed during gaming), Left Alt (thumb-accessible), or a mouse side button if your mouse has extra buttons. Avoid keys you use often in games — WASD, Space, Shift, or Ctrl are bad push-to-talk keys.
